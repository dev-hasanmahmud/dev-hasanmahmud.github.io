Getting Started with Laravel 10: A Beginner’s Guide

By: Hasan Mahmud

Published: July 2025

Laravel is one of the most popular PHP frameworks, known for its elegant syntax and powerful tools...

1. Prerequisites

  • PHP 8.1 or newer
  • Composer
  • MySQL / SQLite
  • Node.js (optional, for frontend tools)

2. Installing Laravel

Run the following command to create a new Laravel project:

composer create-project laravel/laravel blog-app

3. Directory Overview

  • app/ – Application logic (Models, Services, etc.)
  • routes/web.php – Web routes
  • resources/views – Blade templates
  • public/ – Public files (index.php, assets)
  • config/ – Configuration files

4. Creating a Route

Edit routes/web.php:

Route::get('/', function () {
    return view('welcome');
});

5. Creating a Controller

Generate a controller using artisan:

php artisan make:controller HomeController

Edit it:

public function index() {
    return view('home');
}

6. Creating a Blade View

In resources/views/home.blade.php:

<h1>Welcome to My Laravel App</h1>

7. Database Setup

In your .env file:

DB_DATABASE=laravel
DB_USERNAME=root
DB_PASSWORD=

8. Running Migrations

php artisan migrate

9. Running the Server

php artisan serve

Your app will be running at http://localhost:8000.
