Eloquent Tips & Tricks for Laravel Developers

By: Hasan Mahmud

Published: July 2025

Laravel's Eloquent ORM is incredibly powerful. Here are some lesser-known tips and tricks that can boost your productivity and make your code cleaner and more efficient.

1. Chunking Results

When working with large datasets, avoid loading everything into memory:

Post::chunk(100, function ($posts) {
    foreach ($posts as $post) {
        // process
    }
});

2. Attribute Casting

Automatically cast JSON or dates in models:

protected $casts = [
    'is_active' => 'boolean',
    'settings' => 'array',
    'published_at' => 'datetime',
];

3. Local Scopes

Encapsulate query logic in reusable scopes:

// In model
public function scopePublished($query) {
    return $query->where('published', true);
}

// Usage
$posts = Post::published()->get();

4. Eager Loading Count

Post::withCount('comments')->get();

5. Mass Assignment Protection

protected $fillable = ['title', 'body'];

Or use guarded (opposite):

protected $guarded = ['id'];

6. Touching Timestamps

Automatically update parent timestamps when child updates:

protected $touches = ['post'];

These tricks can help you write cleaner, faster, and more maintainable Laravel apps using Eloquent.
